# Kodiman jDownloader Addon / ALPHA

Ein Kodi-Addon zur Integration von [jDownloader](https://jdownloader.org/) über die MyJDownloader-API.

## Funktionen

- Download-Links eingeben und direkt an jDownloader senden
- Aktive Downloads mit Fortschritt anzeigen
- Downloads stoppen oder löschen (Kontextmenü)
- Einfache Konfiguration über die Addon-Einstellungen (E-Mail, Passwort)

## Installation

1. Repository klonen oder ZIP über Releases herunterladen.
2. In Kodi unter **"Addons > Aus ZIP-Datei installieren"** installieren.
3. Zugangsdaten unter **"Einstellungen"** eintragen.

## Abhängigkeiten

- [myjdapi](https://github.com/mmarquezs/My.Jdownloader-API-Python-Library): `pip install myjdapi`
